# Эксперименты

## Обязательный состав эксперимента

Каждый эксперимент должен сохранять:

- `experiment_id`;
- цель и ворота;
- версию стратегии;
- commit SHA кода;
- идентификатор данных;
- набор параметров;
- модель спреда, комиссии, свопа, задержки и проскальзывания;
- начальный депозит и плечо;
- дату запуска;
- полный сырой отчёт;
- сводные метрики;
- решение и объяснение.

## Именование

Использовать `EXP-ГГГГММДД-порядковый_номер`. Пример: `EXP-20260911-001`.

## Неизменяемость

После принятия решения исходные параметры и сырой результат эксперимента не переписываются. Исправленный запуск получает новый ID. Отрицательные результаты сохраняются в `00_Управление_проектом/РЕЕСТР_ЭКСПЕРИМЕНТОВ.csv`.
