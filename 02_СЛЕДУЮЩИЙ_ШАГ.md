## Definition of Done

Migration считается завершённой, когда:

1. новые target files существуют;
2. canonical state указывает только на новые current-v2 paths;
3. README, start guide, AGENTS, AI handoff, backlog и cross-links обновлены;
4. validator требует новые paths и больше не требует старые current-v2 paths;
5. старые current-v2 files удалены только после переноса содержимого;
6. GitHub Actions validation проходит;
7. `ATS2-M0-009` в backlog переведён в `DONE`, а `ATS2-M0-010` — в `READY`.
