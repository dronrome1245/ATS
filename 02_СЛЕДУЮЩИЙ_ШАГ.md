## Назначение

Нужно operationalize formal Experiment preregistration, чтобы результат мог считаться registered evidence только если experiment context зафиксирован до наблюдения результата.

Документ должен определить:

1. stable Experiment ID формата `EXP-YYYYMMDD-nnn`;
2. обязательную связь с `HYP-xxxx` и Candidate/Strategy Version при наличии;
3. code revision / implementation reference;
4. dataset identity / source snapshot / period;
5. parameters/configuration;
6. cost and execution assumptions;
7. predefined research question;
8. primary/secondary metrics;
9. predefined decision rule;
10. research stage / evidence class;
11. random seed или `NOT_APPLICABLE` с причиной;
12. immutable pre-result registration boundary;
13. правила amendment до результата и prohibition post-result rewrite;
14. связь manifest → result → conclusion;
15. structural schema test без fictitious Experiment result.

## Definition of Done

`ATS2-M1-007` можно закрыть, когда formal Experiment однозначно preregistered до result observation, manifest покрывает code/data/config/cost/question/decision context, а post-result изменения не могут быть представлены как исходная preregistration.

## Ограничения

Не создавать fictitious trading result ради проверки schema. Не повышать Cheap Prototype до registered evidence задним числом. Не выбирать Reference Strategy #1, broker, capital/risk limits или live platform.
