# Следующий шаг

## Цель

Закрыть ворота `G01_RISK_MANDATE`.

## Требуемое решение владельца проекта

Нужно зафиксировать согласованные численные пределы:

1. валюта и максимальная сумма отдельного торгового капитала;
2. максимальная сумма, которую допустимо потерять полностью;
3. максимальная допустимая просадка;
4. максимальный срок нахождения капитала в просадке;
5. максимальная доля общего капитала, выделяемая проекту;
6. режим пополнения после убытка;
7. абсолютный уровень аварийной остановки эксперимента.

## Уже принятые ограничения

- Кредиты не используются.
- Финансовая подушка не используется.
- Автоматическое спасение робота дополнительными деньгами запрещено.
- После достижения установленного лимита торговля прекращается.
- Повышение риска после убытков запрещено.
- Числа из первоначального описания являются примерами, а не принятыми лимитами.

## Результат шага

Создать `01_Контур_продукта/РИСК_МАНДАТ.md` с фактическими значениями и решением владельца проекта. После этого:

- изменить `G01` на `PASS`;
- перевести `G02` в `IN_PROGRESS`;
- синхронно обновить три статусных файла;
- запустить `python tools/validate_repo.py`.

Пока численные решения не приняты, текущий статус остаётся `BLOCKED`.
