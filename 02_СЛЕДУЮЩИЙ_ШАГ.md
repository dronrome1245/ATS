## Назначение

Новый research object должен создаваться без повторного проектирования структуры и при этом сразу соответствовать `OPERATING_MODEL_V2.md`, `STRATEGY_LIFECYCLE_V2.md`, `RESEARCH_METHODOLOGY_V1.md` и naming rules из `REPOSITORY_STRUCTURE_V2.md`.

## Обязательные требования

Templates должны:

- иметь устойчивое поле identity/status;
- отличать exploratory объект от formal evidence;
- не содержать выдуманных финансовых/торговых значений;
- поддерживать ссылки между Idea → Hypothesis → Candidate → Strategy/Experiment;
- для Experiment фиксировать code/data/parameters/costs/predefined question/result/conclusion;
- для Strategy Version фиксировать immutable research identity конкретной версии;
- иметь понятные инструкции, какие поля обязательны на соответствующей стадии;
- не использовать незаполненные фиктивные значения как будто они приняты;
- быть пригодными для последующей machine validation.
