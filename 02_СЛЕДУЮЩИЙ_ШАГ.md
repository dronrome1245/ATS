## Следующая program-level ready task

**`ATS2-M2-004 — Base data loader`**

Work package: `WBS-2.4`.

## Следующий обязательный артефакт

`src/ats/data/loader.py`

Supporting fixtures/tests должны находиться under `tests/` и использовать только synthetic non-market data.

## Назначение

Нужно реализовать минимальный deterministic data loader, который потребляет уже валидированный `DatasetManifest` и не создаёт скрытые data semantics.

M2-004 должен минимум:

1. загрузить reference-format dataset, первоначально CSV;
2. связать dataset file с Manifest storage/integrity metadata;
3. распарсить event/availability timestamps согласно Manifest;
4. применить deterministic ordering keys и tie-break keys;
5. обработать duplicates согласно declared policy;
6. обработать malformed records согласно declared policy;
7. обнаружить out-of-order input и применить declared policy;
8. представить declared missing/gap policy без выдуманной market-calendar логики;
9. при `SHA256` проверить фактические dataset bytes;
10. вернуть typed/immutable ordered records suitable for later Strategy/Replay work;
11. иметь deterministic synthetic positive/negative tests.

## Ограничения

M2-004 не должен:

- выбирать Reference Strategy #1;
- добавлять market/vendor-specific ingestion;
- реализовывать Strategy API;
- реализовывать replay/backtest;
- реализовывать costs/analytics;
- добавлять broker/live execution;
- превращать software fixtures в research evidence.
