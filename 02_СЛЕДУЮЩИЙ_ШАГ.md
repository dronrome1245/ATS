## Назначение

Нужно operationalize evidence hierarchy, чтобы тип результата однозначно ограничивал силу допустимого claim и следующий decision.

Документ должен определить минимум:

1. `EXPLORATORY_OBSERVATION` / `EXPLORATORY_PROTOTYPE`;
2. `REGISTERED_EXPERIMENT`;
3. validation evidence;
4. independent examination evidence;
5. stress evidence;
6. demo/shadow evidence;
7. minimal/live evidence;
8. допустимые claims для каждого класса;
9. запрещённые claims для каждого класса;
10. prerequisites для повышения evidence class;
11. запрет повышать class только потому, что result выглядит привлекательно;
12. negative/failed evidence retention;
13. relationship с Experiment Registry и Candidate/Strategy Evidence Index;
14. structural taxonomy test без fictitious trading result.
