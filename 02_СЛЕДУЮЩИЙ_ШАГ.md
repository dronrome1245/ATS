## Назначение

Нужно собрать M1 capabilities в одну повторяемую процедуру review, которая принимает решение по research line на основании сохранённых artifacts и корректно классифицированного evidence.

Документ должен определить минимум:

1. review triggers вместо придуманного обязательного календаря;
2. обязательный input package по текущей lifecycle stage;
3. проверку lineage и актуальности Hypothesis/Candidate/Strategy Version;
4. проверку Data Feasibility/economic assumptions;
5. проверку Experiment registration/Registry completeness, когда formal evidence используется;
6. `source_class` и `qualified_evidence_class` checks по `EVIDENCE_TAXONOMY.md`;
7. evidence sufficiency и unresolved limitations;
8. roles: preparer/reviewer/decision authority и допустимое совмещение ролей;
9. stage-appropriate decisions, включая `PROMOTE / PARK / REJECT`;
10. bounded `RETURN_TO_RESEARCH` без бесконечного спасения идеи;
11. сохранение negative evidence, failed alternatives и dissent;
12. immutable review decision record и follow-up linkage;
13. правила повторного review после material changes/new evidence;
14. structural protocol test без fictitious strategy/evidence.

## Definition of Done

`ATS2-M1-010` можно закрыть, когда новый агент может взять реальный research package, определить достаточность входов/evidence, провести review по одной процедуре, сохранить решение и follow-up без изменения history или post-hoc усиления claims.
