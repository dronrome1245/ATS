`experiments/README.md`

## Назначение

Нужно сделать formal Experiments обнаруживаемыми по stable ID без создания второго source of truth рядом с canonical experiment package.

Registry должен определить/хранить минимум:

1. Experiment ID `EXP-YYYYMMDD-nnn`;
2. status (`REGISTERED/RUNNING/COMPLETED/CANCELLED/SUPERSEDED` либо canonical subset);
3. research stage;
4. evidence class;
5. Hypothesis ID;
6. Candidate/Strategy/Strategy Version linkage при наличии;
7. canonical experiment directory/manifest path;
8. registration anchor/context reference;
9. result/conclusion availability;
10. outcome/decision when known;
11. supersedes/superseded-by linkage;
12. retention of negative/failed/cancelled entries;
13. uniqueness/integrity rules;
14. structural test without fictitious Experiment rows.

## Definition of Done

`ATS2-M1-008` можно закрыть, когда существует один canonical searchable registry, registry не дублирует полный manifest/result/conclusion, negative outcomes не исчезают, stable ID уникален, а state/backlog/handoff/validator синхронизированы.

## Ограничения

Не регистрировать fictitious Experiment ради заполнения registry. Не использовать registry row как замену preregistered manifest. Не выбирать Reference Strategy #1, broker, capital/risk limits или live platform.
