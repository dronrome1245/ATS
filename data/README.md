# Данные

## Назначение

Каталог описывает происхождение и контроль данных, но не предназначен для бесконтрольного хранения больших или лицензируемых брокерских массивов в Git.

## Политика

- Сырые тики не коммитятся без проверки лицензии и размера.
- Для каждого набора создаётся manifest: источник, инструмент, временной диапазон, часовой пояс, качество, пропуски, способ получения и контрольная сумма.
- Периоды разработки, валидации и финального экзамена фиксируются до оптимизации.
- Финальный участок не должен быть доступен разработчику до `G08`.
- Изменение или очистка данных создаёт новую версию manifest.
- Данные другого брокера не считаются автоматически эквивалентными.

## Текущее состояние

Источники, инструменты и периоды не утверждены. Сырые данные отсутствуют.
