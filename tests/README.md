# Тесты

После появления кода тестовый контур должен включать:

- unit-тесты расчётов сигналов и риска;
- тесты граничных значений лота, стопов, маржи и лимитов;
- replay исторических событий;
- интеграционные тесты адаптера исполнения;
- проверку повторного ордера;
- восстановление после перезапуска;
- повреждённые и устаревшие котировки;
- отказ, частичное исполнение и задержку;
- пропуск сигналов;
- аварийную остановку;
- shadow-сверку ожидаемого и фактического поведения.

Конкретные команды тестирования добавляются после принятия платформы.
