# Бэклог задач ATS

## Правила

- Задача привязана к одним основным воротам.
- Завершение задачи не означает прохождение ворот.
- Результат должен иметь проверяемый артефакт.
- Сроки не назначаются, пока не подтверждены исполнитель и доступность входов.
