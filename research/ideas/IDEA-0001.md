## Observation

EUR/USD spot FX may exhibit periods in which directional movement persists across multiple completed 1H bars after price enters a clearly defined upward trend/breakout state relative to prior completed bars.

If such persistence exists, a deterministic long/flat rule that uses only information available after each 1H bar closes may be able to capture part of the subsequent EUR appreciation versus USD before a defined exit condition indicates that the trend has weakened or reversed.

No claim is made yet that this effect exists, is economically meaningful or survives spread, execution costs or multi-day holding costs.

- Market / asset class: `FX_SPOT_OTC`

- Horizon: decision interval `1H`; holding period not fixed and may span multiple hours or calendar days

- Proposed research data path: Dukascopy historical EUR/USD 1H BID/ASK bars, subject to Data Feasibility

Exact historical coverage, timestamp/bar-boundary convention, weekend filtering and source reproducibility remain subject to Data Feasibility review.

## Preliminary rationale

A plausible mechanism is gradual adjustment rather than instantaneous incorporation of all information into price. Persistent order flow, delayed reaction to macro/positioning information and cross-session position adjustment can in principle create multi-bar continuation.

Published time-series-momentum/trend-following literature documents trend persistence as a research phenomenon across multiple markets and horizons. That literature does not establish that the same effect exists in EUR/USD 1H data, so transfer to this instrument/timeframe is the proposition to test rather than an assumption.

The rationale is therefore non-circular: the Idea is not based on an ATS backtest or on a parameter set selected because it made money.

## Expected effect

- Direction/type of effect: `POSITIVE_CONTINUATION_AFTER_UPWARD_TREND_OR_BREAKOUT_STATE`
- Expected observable consequence: after a preregistered upward trend/breakout state formed only from completed EUR/USD 1H bars, subsequent EUR/USD movement should be more positive than an appropriate unconditional/non-signal baseline over one or more **predeclared** forward horizons.

The exact state definition, forward horizons and failure threshold are intentionally deferred to `HYP-0001`. They must be fixed before observing the prototype result.

## Required data

Minimum research inputs:

- EUR/USD 1H OHLC bars with explicit BID/ASK side semantics;
- explicit bar open/close timestamps and timezone/bar-boundary semantics;
- documented weekend/session filtering;
- a frozen source/snapshot reference and integrity reference/hash where reproducibly available;
- next-information-point BID/ASK prices sufficient to model long entry/exit after signal formation;
- explicit spread and fee assumptions where applicable;
- if positions may remain open across rollover, either a reproducible swap/rollover cost input or an explicit early-prototype declaration that rollover is not yet modeled and limits the economic claim;
- metadata on missing bars, source revisions and feed limitations.

Primary candidate source for Data Feasibility is Dukascopy historical data because its API documentation explicitly distinguishes `OfferSide.BID` and `OfferSide.ASK` for `EURUSD` 1H bars.

Alpha Vantage `FX_INTRADAY` with `60min` is a secondary candidate source, but its current intraday FX endpoint is premium and does not by itself resolve the BID/ASK execution-model requirement.

## Cheapest useful test

After `HYP-0001` freezes one deterministic trend/breakout definition and a bounded set of forward horizons:

1. load a frozen EUR/USD 1H dataset through the M2 Dataset Manifest/loader path;
2. compute the signal using only fully completed bars;
3. measure forward EUR/USD continuation after signal bars versus a declared baseline;
4. run a simple long/flat replay with action no earlier than the next information-available point;
5. model long entry using ASK and long exit/valuation using BID where the chosen dataset supports those sides;
6. apply explicit spread/cost sensitivity and handle rollover consistently with the declared prototype scope;
7. report the result without optimizing the rule after seeing it.

This cheap test should be able to weaken or kill the Idea before Candidate admission or production engineering.

## Known risks of false inference

- look-ahead from using the final 1H bar value before the bar is actually closed;
- same-close execution that assumes an unavailable fill after signal computation;
- mixing BID-derived signals with MID/ASK execution inconsistently;
- ignoring spread when evaluating a long/flat FX rule;
- ignoring rollover/swap while allowing multi-day positions and then overstating economic viability;
- choosing lookback, threshold, horizon or exit rule after observing results;
- repeated testing/multiple-comparison bias;
- regime dependence across monetary-policy and volatility regimes;
- source/vendor dependence in decentralized OTC FX;
- session/weekend filtering differences across vendors;
- timestamp or DST/bar-boundary mistakes;
- treating tick volume as centralized market volume;
- interpreting historical trend-following literature as direct evidence for EUR/USD 1H rather than provenance.
