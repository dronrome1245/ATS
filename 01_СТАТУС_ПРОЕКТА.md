## Завершено последним

`ATS2-M2-000 — Reference Consumer Profile` завершена.

Canonical artifact:

`governance/program/REFERENCE_CONSUMER_PROFILE.md`

Профиль определяет минимального M2 consumer как single research-logic instance над finite deterministic ordered event/data stream. Он требует Dataset Manifest, явную timestamp/order semantics, broker-independent research interface, deterministic replay, explicit costs, standard result/analytics, Experiment integration и reproducibility binding `code + environment + data + config + costs + result`.

M2 acceptance использует только deterministic synthetic software fixture. Fixture не является Idea/Hypothesis/Strategy/Experiment и не является trading evidence.
