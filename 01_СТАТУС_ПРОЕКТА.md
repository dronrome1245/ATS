## Repository Structure v2

`REPOSITORY_STRUCTURE_V2.md` определяет целевую архитектуру репозитория:

- root entrypoints и canonical state;
- program governance;
- Research Factory (`Idea`, `Hypothesis`, `Candidate`);
- `Strategy` и immutable context `Strategy Version`;
- shared platform capabilities;
- data manifests и external storage boundaries;
- formal experiments и reports;
- portfolio/operations артефакты;
- отдельное пространство legacy ATS v1;
- naming rules и migration map текущих файлов.

Физическое массовое перемещение существующих файлов не выполнялось. Оно будет разложено на безопасные migration tasks в Program Backlog.
