## Quality gate

GitHub Actions не используется. На Windows canonical OWNER interface для material task — стабильный `ATS_TASK_CHECK.bat`. Task-specific logic хранится в `tools/current_task_check.py`; BAT сам обновляет repository, синхронизирует frozen environment, запускает task checks + full gate и создаёт `reports/local_ci/CURRENT_TASK_REPORT.txt`. При PASS/FAIL OWNER присылает этот TXT.
