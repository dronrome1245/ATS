Два запуска RF-027 дошли до официального BLS и получили HTTP 403 ещё до получения календаря CPI.

Это технический blocker, а не отрицательный результат гипотезы.

Поэтому RF-027 перестраивается на offline-схему:

1. OWNER один раз сохраняет официальные годовые расписания BLS за 2003–2021;
2. ATS считает SHA-256 каждого snapshot-файла;
3. ATS локально строит CPI-календарь;
4. CPI-календарь получает собственный SHA-256;
5. после этого обычный RF-027 больше не обращается к BLS по сети;
6. дальше проверяется только Dukascopy tick geometry.
