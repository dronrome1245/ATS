## M4-005 — что реализовано

Создан:

`src/ats/validation/resampling.py`

Текущий baseline поддерживает только явный:

`BLOCK_BOOTSTRAP`

Это намеренно. Инструмент:

- принимает заранее объявленные блоки зависимости;
- выбирает **целые блоки**, а не отдельные наблюдения;
- сохраняет внутренний порядок внутри блока;
- сохраняет полный список выбранных block ID для каждого replicate;
- требует явный seed;
- повторяется детерминированно;
- не имеет скрытого IID fallback.

Тесты:

`tests/test_validation_resampling.py`

используют синтетические блоки и не создают validation evidence.
