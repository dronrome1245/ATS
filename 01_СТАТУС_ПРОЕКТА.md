## Последний реализованный work package

`ATS2-M2-007 — Cost model interface`.

Primary artifact:

`src/ats/costs/interface.py`

Реализовано:

- immutable explicit `CostModelConfig`;
- named cost components with explicit `APPLICABLE / NOT_APPLICABLE`;
- mandatory parameters for applicable components and an explicit reason for non-applicable ones;
- deterministic `CostInput` outside Strategy logic;
- separate serializable `CostComponentResult / CostResult`;
- canonical JSON serialization without gross/net performance fields;
- `CostModel` protocol and `apply_cost_model` contract validation;
- rejection of silently omitted/reordered components;
- synthetic deterministic cost fixture covering fee, spread proxy and explicit non-applicable slippage proxy.

Это cost abstraction для research platform, не execution simulator и не analytics.
