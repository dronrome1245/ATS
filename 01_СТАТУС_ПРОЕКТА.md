## Завершено последним

`ATS2-M1-008 — Experiment registry` завершена.

Созданы и зафиксированы:

- `experiments/REGISTRY.csv` — единый canonical searchable index formal Experiments;
- registry lifecycle/integrity rules в `experiments/README.md`;
- `tools/search_experiments.py` — stdlib CLI для поиска по ID, status, stage, evidence class, lineage, outcome/decision и свободному substring.

Registry использует одну строку на один реальный `EXP-YYYYMMDD-nnn`, никогда не удаляет negative/failed/cancelled/superseded history и хранит только индексируемое summary. Полный source of truth остаётся в `manifest.yaml → result.json → conclusion.md`.

Initial Registry содержит header и **0 fictitious rows**, поэтому `strategy_pipeline.experiments_registered = 0`.
